# Портал посещаемости

Простой веб-портал для старосты: регистрация по номеру телефона, создание группы, отметка посещаемости, экспорт в Excel и отправка отчета в Telegram.

## Установка

1. Перейдите в папку проекта:
   ```powershell
   cd c:\Users\user\Desktop\портал
   ```
2. Установите зависимости:
   ```powershell
   npm install
   ```

## Переменные окружения

Для отправки уведомлений в Telegram задайте:

- `TELEGRAM_BOT_TOKEN` — токен бота
- `TELEGRAM_CHAT_ID` — ID чата или канала

Вы можете создать файл `.env` и загрузить переменные через `python-dotenv`, но в этой версии достаточно установить их в системе.

## Запуск

```powershell
npm start
```

Откройте в браузере `http://127.0.0.1:5000/`.

## Docker

1. Постройте образ:
   ```powershell
   docker build --no-cache -t portal-attendance .
   ```
2. Запустите контейнер:
   ```powershell
   docker run -p 5000:5000 portal-attendance
   ```
3. Откройте `http://127.0.0.1:5000/`.

Если CSS не загружается (ошибка 404):
- Проверьте `http://127.0.0.1:5000/check-static` — там должна быть информация о файлах.
- Пересоберите образ с `--no-cache`.
- Если порт занят, используйте другой: `docker run -p 5001:5000 portal-attendance`.

## Как пользоваться

1. Нажмите «Регистрация» на главной странице.
2. Введите номер телефона, имя старосты, пароль, название группы, имя куратора и список учеников.
3. После регистрации вы попадете в панель управления.
4. Откройте страницу «Отметить посещаемость», отметьте присутствующих и сохраните.
5. Нажмите «Скачать Excel», чтобы получить отчет.

## Примечания

- В Telegram отправка работает только при заполненных `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
- Все данные сохраняются в файле `portal.db`.
